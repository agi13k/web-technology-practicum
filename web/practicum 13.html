CSS Positioning in Practice

Each box below is a live demo. Scroll this page to see the fixed status pill and Top button stay put, and scroll inside the last box to see sticky work.

1. static (default)

Box A
Box B (static)
Box C

Elements follow normal document flow. top, left and z-index have no effect. Box B has top: 40px but does not move.

.pos-static {
  position: static;
  top: 40px; /* ignored */
}

2. relative

Box A
Box B (relative)
Box C

Offset from its own normal position. The dashed outline shows the space it still occupies, so siblings do not reflow. Also the anchor for absolute children.

.pos-relative {
  position: relative;
  top: 12px;
  left: 30px;
}

3. absolute

.stage (position: relative)
top / right
bottom / left

Removed from the flow and placed against the nearest positioned ancestor. Used for badges, tooltips, dropdown menus and overlays.

.stage { position: relative; }
.pos-abs-tr {
  position: absolute;
  top: 10px;
  right: 10px;
}

4. fixed

● status↑ Top

Positioned against the viewport, so it ignores scrolling. Look at the bottom corners of this page: the dark status pill and the Top button are both position: fixed.

.fab-top {
  position: fixed;
  right: 20px;
  bottom: 20px;
  z-index: 100;
}

5. sticky

Sticky header: stays at top: 0 of this box

Scroll inside this box. Content moves, the header stays.

Sticky behaves like relative until a scroll threshold is reached, then behaves like fixed within its container.

This page's navigation bar uses the same idea against the whole viewport.

The table in the Process section keeps its column headings visible the same way.

Other uses: section titles in long lists, sidebars with a table of contents, shopping cart summaries.

The sticky element always stays inside its parent, so when the parent ends, the element scrolls away with it.

Remember: a sticky element needs a threshold such as top: 0, and no ancestor between it and the scroller may have overflow: hidden.

.sticky-head {
  position: sticky;
  top: 0;
  z-index: 5;
}
